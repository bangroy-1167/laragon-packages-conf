# Laragon packages.conf

English

This repository contains a public `packages.conf` file for Laragon's Quick Add feature.

Laragon uses `packages.conf` to define download URLs and package metadata for tools such as PHP, web servers, databases, Node.js, VS Code, Go, and other development utilities. The file is used by Laragon's UI to help users quickly add or update software without manually downloading archives.

This repository is intended as a public reference version of the configuration file, based on the official Laragon package source format.

## Files

- `packages.conf` — package download definitions for Laragon Quick Add
- `README.md` — bilingual documentation (English / Indonesian)

## Purpose

The `packages.conf` file is the configuration behind Laragon's Quick Add feature. It defines the links for installing or upgrading:

- PHP
- Apache
- Nginx
- MySQL
- PostgreSQL
- MongoDB
- Node.js
- VS Code
- Go
- phpMyAdmin
- other supporting tools

## Usage

Place this file in the same directory structure expected by your Laragon setup, or use it as a reference when customizing package sources for Quick Add.
